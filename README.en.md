# Little Math Explorer

An interactive math learning space for primary school where math comes to life.

> **Language:** [Read this in Chinese](/README.md) · [Chinese version](/README.zh-CN.md)

## One-click launch

Double-click `start.bat` in the project root.

The script does the following automatically:

- Checks that Node.js and npm are available
- Installs project dependencies on first run
- Starts the Vite development server
- Opens the browser automatically

If the browser does not open automatically, visit `http://127.0.0.1:5173/`.

Requires Node.js 20 or later. To stop the server, press `Ctrl+C` in the command window.

## Technology

- React 19 + TypeScript
- Three.js via @react-three/fiber and @react-three/drei
- Vite
