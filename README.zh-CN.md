# 小小数学家

一个让数学动起来的小学互动学习空间。

> **语言：** [English version](/README.en.md) · [查看英文说明](/README.en.md)

## 一键启动

双击项目根目录下的 `start.bat`。

脚本会自动完成以下操作：

- 检查 Node.js 和 npm 是否可用
- 首次运行时安装项目依赖
- 启动 Vite 开发服务器
- 自动打开浏览器

如果浏览器没有自动打开，可以访问 `http://127.0.0.1:5173/`。

需要 Node.js 20 或更高版本。停止服务时，在命令窗口按 `Ctrl+C`。

## 技术栈

- React 19 + TypeScript
- Three.js（经由 @react-three/fiber 与 @react-three/drei）
- Vite
